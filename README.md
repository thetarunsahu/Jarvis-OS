# JARVIS OS

> A personal AI operating layer built from scratch.

JARVIS OS is an experimental personal AI system designed to understand natural language, remember context, use tools, interact with the computer, and eventually connect with the physical world through IoT.

## Vision

The goal is not to build another chatbot.

JARVIS is designed as an intelligent layer between the user and their digital environment.
